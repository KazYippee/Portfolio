# 📸 Image Guidelines

## Required Images for Your Portfolio

### 1. Profile Photo (`profile-photo.jpg`)
- **Dimensions**: 400x400 pixels (square)
- **File size**: Under 1MB
- **Format**: JPG or PNG
- **Location**: Save in `images/` folder

**Tips for a great profile photo:**
- Professional headshot style
- Clean, simple background
- Good lighting (natural light preferred)
- Dress professionally
- Smile naturally
- Face should fill about 60% of the frame

### 2. Portfolio/Project Images
Save as `project1.jpg`, `project2.jpg`, `project3.jpg`, `project4.jpg`

- **Dimensions**: 600x400 pixels (landscape)
- **File size**: Under 1MB each
- **Format**: JPG or PNG
- **Location**: Save in `images/` folder

**Project image ideas:**
- Screenshots of websites you've built
- Photos of physical projects
- Certificates or awards
- Presentation slides
- Team photos from projects
- Before/after comparisons
- Data visualizations or charts

### 3. Image Preparation Tools

**Free Online Tools:**
- **Canva**: Create professional layouts
- **Remove.bg**: Remove backgrounds
- **TinyPNG**: Compress file sizes
- **Pixlr**: Basic photo editing

**Phone Apps:**
- **Snapseed** (free photo editing)
- **VSCO** (filters and editing)
- **Adobe Lightroom Mobile** (free version)

### 4. Image Sources (if you need stock photos temporarily)

**Free Stock Photo Sites:**
- Unsplash.com
- Pexels.com  
- Pixabay.com

**Professional Photo Services:**
- LinkedIn photographers in your area
- Local photography studios
- Corporate headshot services

### 5. File Naming Convention

```
images/
├── profile-photo.jpg     # Your headshot
├── project1.jpg          # Main portfolio piece
├── project2.jpg          # Second project
├── project3.jpg          # Third project  
└── project4.jpg          # Fourth project
```

**Important**: File names are case-sensitive and must match exactly!

### 6. Quick Image Resize Guide

**Using Phone:**
1. Take photo
2. Go to Photos app
3. Select photo → Edit → Crop
4. Choose "Square" for profile photo
5. Choose "16:9" or custom for project images
6. Save

**Using Computer:**
1. Right-click image
2. "Open with" → Paint (Windows) or Preview (Mac)
3. Resize to required dimensions
4. Save as JPG

### 7. Image Quality Checklist

Before uploading, check:
- [ ] File name matches template requirements exactly
- [ ] Image is clear and not blurry
- [ ] File size is under 1MB
- [ ] Colors look good on different devices
- [ ] Professional appearance
- [ ] Proper dimensions

### 8. Backup Strategy

Always keep:
- Original high-resolution versions
- Edited web versions
- Multiple file format options (JPG/PNG)

This ensures you can always make changes or use images elsewhere!

*Remember: These images represent you professionally, so invest time in getting them right!*
