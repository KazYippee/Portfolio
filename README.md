# 🌟 Portfolio Generator with File Upload System

Generate professional portfolio websites with automatic file uploads and ZIP packaging for GitHub Pages deployment.

## 🚀 How to Use This Generator

### Step 1: Open the Generator
```bash
# Double-click or open in browser:
portfolio-generator.html
```

### Step 2: Fill in Your Information
Complete all the required sections:

#### Personal Information
- **Full Name**: Your complete name
- **Professional Title**: Your job title or role
- **About Me**: 2-3 sentence description of yourself

#### Upload Your Files
1. **Profile Photo** 📷
   - Click upload area or drag & drop
   - Requirements: Square format (400x400px), JPG/PNG/WEBP, max 5MB
   - Professional headshot recommended

2. **Experience Images** 🖼️
   - Upload one image per experience/project
   - Requirements: Landscape format (600x400px), JPG/PNG/WEBP, max 5MB each
   - Project screenshots, work samples, or relevant photos

3. **Resume** 📄
   - Upload your current resume
   - Requirements: PDF format only, max 10MB
   - Will be downloadable from your portfolio

#### Contact & Skills
- Email, phone, location
- Add multiple skills (click "Add Another Skill")
- Social media links (LinkedIn, GitHub, Twitter)

#### Experience & Projects
- Add multiple experiences/projects
- Each includes: title, uploaded image, description
- Click "Add Another Experience" for more entries

#### Choose Your Theme 🎨
Select from 6 professional color themes:
- Professional Blue
- Nature Green  
- Creative Purple
- Energetic Orange
- Modern Teal
- Bold Red

### Step 3: Generate Your Portfolio
1. Click **"🚀 Generate My Portfolio"**
2. Watch the progress bar (files are being packaged)
3. Download will start automatically

### Step 4: What You Get
Your ZIP file contains everything needed:
```
your-name-portfolio.zip
├── index.html          # Complete website
├── style.css          # Themed styling
├── script.js          # Interactive features
├── images/
│   ├── profile.[ext]   # Your profile photo
│   ├── experience-1.[ext]
│   └── experience-2.[ext]
├── files/
│   └── resume.pdf      # Your resume
├── README.md          # Setup instructions
└── SETUP.md          # GitHub deployment guide
```

### Step 5: Deploy to GitHub Pages

#### Create Repository
1. Go to [github.com](https://github.com)
2. Create new repository named: `yourusername.github.io`
3. Make it **Public** (required for free hosting)

#### Upload Files
1. Extract your ZIP file
2. Upload ALL contents to your repository
3. Commit changes

#### Enable GitHub Pages
1. Go to Settings → Pages
2. Source: "Deploy from a branch"
3. Branch: "main" 
4. Folder: "/ (root)"
5. Save

🎉 **Your portfolio will be live at:** `https://yourusername.github.io`

## 🛠️ Troubleshooting

### File Upload Issues
- **"File too large"**: Compress images or reduce file size
- **"Invalid format"**: Use JPG/PNG/WEBP for images, PDF for resume
- **Upload fails**: Check internet connection, try different browser

### Generation Issues  
- **Missing required fields**: Fill in all fields marked with *
- **No files uploaded**: Must upload profile photo and resume
- **ZIP won't download**: Try different browser or disable pop-up blocker

### GitHub Pages Issues
- **Site not loading**: Check repository name is `username.github.io`
- **Images missing**: Ensure all files from ZIP were uploaded
- **Styling broken**: Verify all CSS and JS files uploaded

## 💡 Pro Tips

### Content Writing
- Write in first person ("I am..." not "John is...")
- Use action verbs and quantifiable achievements
- Keep descriptions concise but informative
- Proofread for grammar and spelling

### Image Optimization
- Use high-quality, professional photos
- Ensure good lighting and composition
- Crop to exact recommended dimensions
- Compress large files before uploading

### Best Practices
- Prepare all content and files before starting
- Review generated portfolio before deploying
- Keep resume and content updated regularly
- Test portfolio on different devices
