Choose Your Multi-User Approach

🎯 Option 1: Template Repository (Recommended)
Each user creates their own repository from your template. Best for individual ownership and GitHub Pages hosting.

✅ Pros

  • Each user gets username.github.io URL
  • Individual ownership and control
  • No version conflicts
  • Easy to maintain
  • Standard GitHub workflow

❌ Cons

  • Requires basic GitHub knowledge
  • Updates need manual propagation
  • Each user needs GitHub account
📁 Option 2: Subdirectory Structure
All portfolios in one repository with individual folders. Good for centralized management.

✅ Pros

  • Centralized management
  • Easy bulk updates
  • Single repository to maintain
  • Organization landing page

❌ Cons

  • URLs are org.github.io/username/
  • Version control conflicts possible
  • Less individual control
  • Requires coordination for updates
🏢 Option 3: Organization Repositories
Create individual repositories under your organization account for centralized branding.

✅ Pros

  • Professional org branding
  • Custom subdomain possible
  • Individual repositories
  • Centralized billing/management

❌ Cons

  • Requires GitHub Organization
  • More complex setup
  • May need paid plan for private repos

📋 Quick Setup Recommendations

For Small Teams (2-10 people): Use Option 1 (Template Repository)

For Large Organizations (10+ people): Use Option 3 (Organization Repositories)

For Tight Control/Branding: Use Option 2 (Subdirectory Structure)

📋 Complete Setup Guide

🎯 Template Repository Method (Recommended)

1

Create the Template Repository

Upload your portfolio template to GitHub and mark it as a template repository.

1. Create new repository: "portfolio-template" 2. Upload all template files (index.html, style.css, script.js, etc.) 3. Go to Settings → Template repository → Check the box 4. Add clear README with instructions
2

Team Member Setup

Each team member creates their portfolio from your template.

1. Go to your template repository 2. Click "Use this template" button 3. Name new repository: "username.github.io" 4. Make repository Public 5. Enable GitHub Pages in Settings
3

Customize Content

Each person updates their information using the portfolio generator.

1. Use the Portfolio Generator to create personalized files 2. Replace template files with generated ones 3. Add profile photo and resume 4. Test the website at username.github.io
